# Momento Hackathon Win Strategy

## Winning thesis

**Momento transforms every official football event into a shared social experience where fans capture, champion and collectively decide the defining moment of every match.**

The project can score highly because TxLINE is not a hidden backend dependency. Its official events directly create the consumer interaction: a goal or card becomes a Capture prompt, each fan Moment stays tied to that official event, and final match state closes Champion actions and reveals the community's defining Moment.

## Why judges should remember it

### 1. TxLINE creates the product mechanic

Many entries can display scores. Momento uses TxLINE events as the trigger for creation, conversation, ranking and finality. Removing TxLINE would remove the core loop, which demonstrates meaningful integration.

### 2. It is consumer-first

The experience is immediately understandable on a phone: watch the official timeline, capture a 15-second reaction and champion the Moment that best expresses the match. Wallets and technical proof do not obstruct participation.

### 3. It has a distinctive verb

`Champion` is active, positive and memorable. It is more differentiating than Support and avoids the financial ambiguity of Back. The phrase `Champion the defining Moment` is strong demo language.

### 4. The demo has an emotional payoff

The five-minute story does not end on a dashboard. It moves from a goal through a real upload and community action to a winner reveal. The product has a beginning, participation loop and conclusion.

### 5. It is reliable enough to judge

Replay uses recorded authorized TxLINE data through the production normalizer and is clearly labeled. Judges see the exact product even when no match is live, without being misled.

### 6. The technical scope is credible

Next.js + Supabase + TxLINE snapshots can be built in 30 hours. MP4 upload has no media pipeline. Champion is one atomic database action. Blockchain is one optional reward receipt, not a custom protocol.

## Judging proof map

| Likely judging value | What Momento shows |
|---|---|
| TxLINE usage | Canonical fixture, score, official event rail, Capture association and final state |
| Product differentiation | Official events become shared social creation windows |
| Consumer experience | Premium mobile match room, vertical Moments and one-thumb Capture |
| Technical quality | Same normalizer for snapshots/replay, truthful modes, idempotent Champion action |
| Working product | Real deployed MP4 upload, Champion count, ranking, chat and winner |
| Reliability | Guided replay, cached data and snapshot polling fallback |
| Business potential | Sponsor-funded creator rewards and branded match communities without betting |

## Features that matter most

1. **Official event rail:** makes TxLINE visible and understandable.
2. **Event-linked Capture:** the key differentiated mechanic.
3. **Real MP4 upload:** proves this is not a mockup.
4. **Champion action and Momentum Meter:** creates the social decision loop.
5. **Winner reveal:** gives the demo a satisfying conclusion.
6. **Replay indicator and provenance:** proves reliability and honesty.
7. **Responsive premium match room:** wins the consumer-experience impression.

## Absolute non-negotiables

- Public working URL.
- Demo video under five minutes.
- Real TxLINE fixture and score integration, plus labeled replay fallback.
- Official event visibly linked to a fan Moment.
- Real MP4 upload to Supabase Storage.
- Real Champion action with correct count after refresh.
- Responsive match room at mobile and desktop widths.
- Final whistle lock and deterministic winner reveal.
- Exact endpoint list and honest TxLINE feedback.

If any of these are missing, stop optional work and fix them.

## Cut immediately if time runs short

1. Solana reward transfer; retain `Community winner confirmed`.
2. TxLINE SSE; retain 10-second score snapshot polling.
3. Live chat creation; retain a visually populated seed discussion if necessary.
4. Moment comments and nested conversations.
5. Merkle proof drawer and advanced health diagnostics.
6. Upcoming/recent fixture filters.
7. 3D artifact and nonessential animation flourishes.

## Never build during the hackathon

- Custom Anchor program, escrow, token or on-chain Champion action.
- Video transcoding, compression, automated captions or background processing.
- Follow graph, recommendation engine, notifications or advanced moderation.
- Multi-sport/multi-competition abstractions before the featured football match works.
- Enterprise observability or microservice orchestration.

## Five-minute impression strategy

### First 30 seconds

State the exact positioning and show the match room immediately. Judges should know both the problem and TxLINE's role before the first minute.

### Middle three minutes

Show causality, not a feature tour:

`TxLINE goal -> Capture prompt -> real MP4 Moment -> Champion -> ranking changes`.

### Final minute

Show TxLINE finality, locked Champion actions, the winner reveal and optional reward receipt. Close on the central message, not the technology stack.

## Presentation language

Use:

- `Official event, shared experience.`
- `Champion the defining Moment.`
- `TxLINE tells us what happened; fans decide what it meant.`
- `Recorded TxLINE data in replay mode.`

Avoid:

- `Bet`, `stake`, `market price`, `odds`, `position`, `yield` or `cash out`.
- Claiming replay is live.
- Describing backend components before the user value is visible.
- Promising automated rewards if the transaction is not working.

## Final go/no-go scorecard

| Test | Go condition |
|---|---|
| Product message | Every presenter can say the positioning verbatim |
| TxLINE | Fixture and score snapshot work or replay is clearly labeled |
| Core loop | Capture, upload, Champion and winner succeed three times |
| Visual quality | 390px and 1440px have no overflow or broken hierarchy |
| Demo reliability | Guided replay reset works in under five seconds |
| Submission | URL, video, technical notes, endpoint list and feedback are ready |

## Final recommendation

Win through clarity and execution, not breadth. A single beautifully executed match that visibly turns TxLINE data into collective fan participation is stronger than a broader platform with wallets, markets and infrastructure that the judges cannot experience.
